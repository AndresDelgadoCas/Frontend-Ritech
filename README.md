# RiTech SAS — Frontend Marketplace

Este proyecto React/TypeScript está integrado con el backend Spring Boot de RiTech SAS. Para instalación, variables de entorno y despliegue consulta `../README-MARKETPLACE.md`.

Comandos locales: `npm ci` y `npm run dev`. Configura `VITE_API_URL` en `.env` con el origen del backend, sin el sufijo `/api`.
